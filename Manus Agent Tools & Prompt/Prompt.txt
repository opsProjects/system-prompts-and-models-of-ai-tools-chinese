# Effective Prompting Guide
# 有效提示指南

## Introduction to Prompting
## 提示简介

This document provides guidance on creating effective prompts when working with AI assistants. A well-crafted prompt can significantly improve the quality and relevance of responses you receive.
本文档提供了在使用 AI 助手时创建有效提示的指南。精心制作的提示可以显着提高你收到的回复的质量和相关性。

## Key Elements of Effective Prompts
## 有效提示的关键要素

### Be Specific and Clear
### 具体且清晰
- State your request explicitly
- 明确陈述你的请求
- Include relevant context and background information
- 包括相关上下文和背景信息
- Specify the format you want for the response
- 指定你想要的回复格式
- Mention any constraints or requirements
- 提及任何约束或要求

### Provide Context
### 提供上下文
- Explain why you need the information
- 解释你为什么需要这些信息
- Share relevant background knowledge
- 分享相关背景知识
- Mention previous attempts if applicable
- 如果适用，提及之前的尝试
- Describe your level of familiarity with the topic
- 描述你对该主题的熟悉程度

### Structure Your Request
### 构建你的请求
- Break complex requests into smaller parts
- 将复杂请求分解为更小的部分
- Use numbered lists for multi-part questions
- 对多部分问题使用编号列表
- Prioritize information if asking for multiple things
- 如果要求多件事，请优先考虑信息
- Consider using headers or sections for organization
- 考虑使用标题或部分进行组织

### Specify Output Format
### 指定输出格式
- Indicate preferred response length (brief vs. detailed)
- 指示首选回复长度（简短与详细）
- Request specific formats (bullet points, paragraphs, tables)
- 请求特定格式（要点、段落、表格）
- Mention if you need code examples, citations, or other special elements
- 提及你是否需要代码示例、引用或其他特殊元素
- Specify tone and style if relevant (formal, conversational, technical)
- 如果相关，指定语气和风格（正式、对话、技术）

## Example Prompts
## 示例提示

### Poor Prompt:
### 糟糕的提示：
"Tell me about machine learning."
“告诉我关于机器学习的信息。”

### Improved Prompt:
### 改进的提示：
"I'm a computer science student working on my first machine learning project. Could you explain supervised learning algorithms in 2-3 paragraphs, focusing on practical applications in image recognition? Please include 2-3 specific algorithm examples with their strengths and weaknesses."
“我是一名计算机科学专业的学生，正在做我的第一个机器学习项目。你能用 2-3 段话解释监督学习算法吗，重点是图像识别中的实际应用？请包括 2-3 个具体算法示例及其优缺点。”

### Poor Prompt:
### 糟糕的提示：
"Write code for a website."
“为一个网站编写代码。”

### Improved Prompt:
### 改进的提示：
"I need to create a simple contact form for a personal portfolio website. Could you write HTML, CSS, and JavaScript code for a responsive form that collects name, email, and message fields? The form should validate inputs before submission and match a minimalist design aesthetic with a blue and white color scheme."
“我需要为一个个人作品集网站创建一个简单的联系表格。你能为一个收集姓名、电子邮件和消息字段的响应式表格编写 HTML, CSS 和 JavaScript 代码吗？该表格应在提交前验证输入，并符合简约设计美学，采用蓝白配色方案。”

## Iterative Prompting
## 迭代提示

Remember that working with AI assistants is often an iterative process:
请记住，与 AI 助手合作通常是一个迭代过程：

1. Start with an initial prompt
1. 从初始提示开始
2. Review the response
2. 查看回复
3. Refine your prompt based on what was helpful or missing
3. 根据有用或缺失的内容完善你的提示
4. Continue the conversation to explore the topic further
4. 继续对话以进一步探索该主题

## When Prompting for Code
## 当提示代码时

When requesting code examples, consider including:
请求代码示例时，请考虑包括：

- Programming language and version
- 编程语言和版本
- Libraries or frameworks you're using
- 你正在使用的库或框架
- Error messages if troubleshooting
- 如果进行故障排除，请提供错误消息
- Sample input/output examples
- 示例输入/输出示例
- Performance considerations
- 性能注意事项
- Compatibility requirements
- 兼容性要求

## Conclusion
## 结论

Effective prompting is a skill that develops with practice. By being clear, specific, and providing context, you can get more valuable and relevant responses from AI assistants. Remember that you can always refine your prompt if the initial response doesn't fully address your needs.
有效提示是一项随着实践而发展的技能。通过清晰、具体并提供上下文，你可以从 AI 助手那里获得更有价值和相关的回复。请记住，如果初始回复未能完全满足你的需求，你总是可以完善你的提示。
